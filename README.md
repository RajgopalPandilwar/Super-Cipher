# Super Cipher — Cryptography Project

A triple-layer cryptography system that uses numerical, alphabetical, and symbol-based keys to provide three layers of security. Each layer applies a different cipher technique, making the encoded message extremely difficult to decode without all three keys.

## How It Works

The Super Cipher applies three sequential encryption layers:

1. **Numerical Key Layer** — Shifts characters based on a numeric key
2. **Alphabetical Key Layer** — Applies a Vigenère-style cipher with an alphabetic key
3. **Symbol Key Layer** — Uses symbol-based substitution for the final layer

Decryption reverses these steps in opposite order.
